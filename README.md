# SmartTaskApi

ASP.NET Core Web API project built for learning enterprise-grade backend development.

## Features

* ASP.NET Core Web API
* Swagger Integration
* REST API
* GitHub Integration
* Unit Testing
* AI-Assisted Development

## Technologies

* .NET 8
* ASP.NET Core
* Swagger
* Git
* GitHub
* xUnit

## API Endpoints
* `GET /api/tasks` - Retrieve all tasks
* `POST /api/tasks` - Create a new task
* `PUT /api/tasks/{id}` - Update an existing task
* `DELETE /api/tasks/{id}` - Delete a task
